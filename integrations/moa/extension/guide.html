NAIS CUSTOM + MOA / START HERE

NAIS + 모아, 처음부터 따라 하기

Windows 10/11 · NAIS3 Custom 1.0.22 · 모아 0.3.12

여러 사이트의 댓글·답글·좋아요·팔로우·공지 알림을 NAIS 한곳에서 보는 기능이에요.

컴퓨터마다 처음 한 번 연결하면 돼요. 코드를 작성하거나 별도 서버를 설치할 필요는 없어요.

1. 파일 두 개 받기

다운로드 페이지의 Assets를 펼쳐 아래 두 파일을 받으세요.

  • nais3-custom-1.0.22-setup.exe — NAIS 설치 프로그램
  • moa-extension-0.3.12.zip — Chrome에 넣을 모아 확장

Source code, blockmap, SHA256SUMS.txt는 처음 설치할 때 받지 않아도 돼요.

MOA-START-HERE.html은 더블클릭해서 읽는 설명서예요. 확장 ZIP 안에도 같은 설명서가 들어 있어요.

2. NAIS 설치하기

  1. 받은 setup.exe를 더블클릭해서 설치해요.
  2. 설치가 끝나면 바탕화면의 NAIS3 Custom 1을 열어요.
  3. 앱에서 알림 탭을 눌러요.

두 번째 프로필인 Custom 2는 선택 사항이에요. 알림은 Custom 1에서 사용해요.

기존 사용자는 작업 중인 이미지 생성이 끝난 뒤 NAIS를 종료하고 업데이트해 주세요.

3. Chrome에 모아 넣기

  1. 받은 ZIP을 마우스 오른쪽 버튼으로 눌러 모두 압축 풀기를 선택해요.
  2. 압축을 푼 폴더 안의 moa-extension 폴더를 오래 보관할 위치에 놓아요. 예: 문서 폴더.
  3. 평소 사이트에 로그인해서 쓰는 Chrome을 열어요. 시크릿 창은 사용하지 않아요.
  4. 주소창에 chrome://extensions를 입력하고 Enter를 눌러요.
  5. 오른쪽 위의 개발자 모드를 켜요.
  6. 압축해제된 확장 프로그램을 로드합니다를 누르고 moa-extension 폴더를 골라요.
  7. 모아 · 내 알림 수집기 / 0.3.12 카드가 보이면 성공이에요.
  8. Chrome 오른쪽 위 퍼즐 아이콘을 누르고 모아 옆의 핀을 눌러두면 편해요.

고를 폴더는 manifest.json 파일이 들어 있는 폴더예요. ZIP 파일 자체를 고르는 게 아니에요.

설치한 moa-extension 폴더를 지우거나 다른 곳으로 옮기지 마세요. Chrome이 그 폴더의 파일을 사용해요.

4. NAIS와 모아 연결하기

  1. NAIS3 Custom 1 → 알림 → 연결 관리를 열어요.
  2. 연결 코드 복사를 눌러요.
  3. Chrome의 모아 아이콘을 눌러요. 안 보이면 퍼즐 아이콘에서 모아를 골라요.
  4. 코드 칸을 누르고 Ctrl+V로 붙여넣어요.
  5. 대시보드 연결을 눌러요.

연결 코드는 자신의 NAIS에서 복사해요. 다른 사람이 보내준 코드를 쓰지 않아요.

5. 내 사이트 계정 연결하기

  1. 모아를 설치한 같은 Chrome 프로필에서, 사용하는 사이트에 로그인해요.
  2. 모아 아이콘을 누르고 계정 API 연결을 한 번 눌러요.
  3. 계정 확인을 위해 사이트 탭이 순서대로 잠깐 열릴 수 있어요. 연결이 끝날 때까지 기다려요.
  4. NAIS의 알림 화면으로 돌아와 수집 결과를 확인해요.

Chrome에 구글 계정으로 로그인하는 것과 각 사이트에 로그인하는 것은 달라요.

알림을 받을 사이트에 로그인돼 있어야 해요. 비밀번호나 인증 토큰을 모아에 직접 입력할 필요는 없어요.

지원 사이트: 에덴, 베이비챗, 루나, 엘린, 네코, 티팟, 크랙, 알플레이, 제닛.

모두 가입할 필요는 없어요. 사용하는 사이트만 로그인하면 돼요.

현재 연결 버튼은 지원 사이트를 순서대로 확인하므로, 사용하지 않는 사이트도 잠시 열릴 수 있어요.

로그인하지 않은 사이트는 미연결로 표시될 수 있어요.

평소에는 이렇게 써요

  • NAIS3 Custom 1 + 모아가 설치된 Chrome을 함께 켜둬요. 최소화해도 돼요.
  • 연결을 마친 사이트 탭은 닫아도 돼요. 일반 Chrome 창 하나는 유지해 주세요.
  • NAIS 알림 화면 오른쪽 위 수집 주기에서 시간을 골라요. 처음에는 1시간이에요.
  • 앱이나 Chrome을 종료하면 수집은 멈춰요. 다시 켜면 저장된 연결 정보가 유효한 동안 설정한 주기에 맞춰 수집해요.
  • 이미 저장된 알림은 Chrome을 꺼도 NAIS에서 볼 수 있어요. 꺼둔 사이의 모든 알림을 빠짐없이 복구한다고 보장하지는 않아요.
  • 원본 사이트에 읽음 처리나 삭제 요청을 보내지 않아요. 대부분 API로 조회하고, 루나는 알림 페이지 응답을 읽어요.
  • 알림 목록 옆 새로고침 버튼은 저장된 목록을 다시 보여주는 버튼이에요. 수집 시각은 화면의 다음 수집 안내를 봐주세요.

안 될 때는 이것부터 봐요

NAIS에 알림 탭이 없어요

Custom 1인지 확인해요.

연결 코드가 안 보여요

연결 관리를 열어요. 이미 연결했다면 코드 버튼이 없어지는 게 정상이에요.

모아 연결이 안 돼요 / LOCAL_HTTP 오류

Custom 1이 켜져 있는지 확인해요. 처음 연결하는 중이라면 자신의 NAIS에서 코드를 다시 복사해요.

계정 재연결이 필요해요 / 로그인이 필요한 탭이 열려요

그 사이트를 사용한다면 같은 Chrome에서 다시 로그인한 뒤 모아의 계정 API 연결을 눌러요.

사용하지 않는 사이트까지 가입할 필요는 없어요.

아직 새 알림이 안 와요

수집 일시정지 상태면 수집 재개를 눌러요. 다음 수집 시각까지 기다려 주세요.

처음 연결할 때는 여러 사이트를 순서대로 처리해요. 기존 설정의 다음 수집 시각이 남아 있다면 그때 조회해요.

모아의 지금 API 조회도 NAIS의 일시정지·수집 시간 제한을 무시하지는 않아요.

일부 사이트만 안 돼요

사이트 자체 오류나 응답 지연도 있어요. 먼저 해당 사이트가 정상적으로 열리는지 확인해요.

확장 설치 시 manifest 오류가 나요

ZIP을 풀었는지, manifest.json이 들어 있는 moa-extension 폴더를 골랐는지 확인해요.

다음 업데이트는 어떻게 하나요?

  • NAIS: 작업을 마치고 앱을 종료한 뒤 새 설치 파일을 실행해요. 프로필 데이터는 유지돼요.
  • 모아: 새 ZIP을 풀고, 처음 설치했던 moa-extension 폴더에 내용물을 덮어써요. 그다음 chrome://extensions의 모아 카드에서 새로고침(↻)을 눌러요.
  • 확장을 삭제하거나 다른 폴더에서 새로 설치하지 마세요. 기존 연결을 유지하려면 같은 폴더를 사용해요.
  • Chrome 웹스토어 버전은 아직 없어요. 이 배포본은 ZIP으로 설치하며 자동 업데이트되지 않아요.

내 정보는 어디에 저장되나요?

알림은 자신의 PC에 있는 NAIS Custom 1 프로필에, 사이트 연결에 필요한 인증 정보는 자신의 Chrome 확장 저장소에 보관돼요.

알림은 로그인한 사이트와 이 컴퓨터의 NAIS 사이에서 오가며, 모아 개발자 서버로 전송하지 않아요.

이 설치 파일에는 제작자의 로그인 정보·알림·이미지 DB가 들어 있지 않아요.

사용을 중단하려면 NAIS의 수집 일시정지를 눌러요.

모아 확장을 제거하면 Chrome에 저장한 모아 연결 정보도 지워져요. NAIS에 이미 저장한 알림은 별도로 남아요.

설명서는 인터넷 없이 열 수 있어요. 다운로드 링크만 인터넷 연결이 필요해요.
